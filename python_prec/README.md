해당 폴더는 파이썬 기초를 다지기 위해 작성한 '국방 C4I/무기체계 시뮬레이션 소스코드'를 모아둔 공간입니다.

📌 **주요 파일 설명**
1. army1.py : C4I 야전 지휘 통제 시스템
   **✅ 주요 기능 ✅**
   - 적 표적을 설정(표적번호, 표적명, 위험등급)
   - 보유 타격 자원 지정(자원명, 수량) 및 화력 타격 시 차감 및 사격 제어
   - 정찰 드론을 기반으로 신규 표적 실시간 등록
   - 작전 일지 파일 저장('log.txt', File I/O)
  
2. army2.py : 대공 미사일 좌표 추적 및 요격 시뮬레이터
   **✅ 주요 기능 ✅**
   - 적 비행물체 위치 좌표 및 위험도 실시간 랜덤 함수 생성
   - 오차 범위 판정 알고리즘을 통한 요격 성공/실패 판정
   - 잔여 요격 미사일 수량 관리 및 자동 감시 루프
  
3. army3.py : 잠수함 소나 음향 탐지 & 어뢰 발사 제어 시스템
   **✅ 주요 기능 ✅**
   - 아군/적군 잠수함 식별 및 신규 신호 등록
   - 교전 거리 판정 및 어뢰 발사/재장전 제어
   - 소나 탐지 및 교전 이력 파일 저장('sonar_log.txt')
  
**C4I 체계** : 군 지휘통제 종합 정보 시스템
**sonar** : 음파를 이용해 수중 목표물을 탐지 및 식별하는 장비
